# Nimbus

Nimbus 是一个基于 **Muduo** 网络库和 **Ceph** 分布式存储系统实现的云盘项目，作为毕业设计开发。该系统支持高并发文件上传、下载、管理等功能，具备良好的扩展性和高可用性。

## 技术架构

- **Muduo**：高性能 C++ 网络库，负责实现高并发的 TCP 服务器，处理客户端的连接与数据传输。
- **Ceph**：开源分布式存储系统，负责后端文件的可靠存储与管理，支持对象存储和高可用性。

## 主要功能

- 用户文件的上传、下载与删除
- 多用户并发访问支持
- 文件分块存储与断点续传
- Ceph 后端高可用、可扩展的分布式存储
- 简单的命令行客户端与服务端
