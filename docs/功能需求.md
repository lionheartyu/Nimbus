# Nimbus 云盘功能需求（实际实现版）

### 1. 基础文件操作

- 文件上传（支持大文件分片上传、断点续传）//将大文件切分为多个小分片上传，最后在服务端合为完整的文件
- 文件下载（支持断点续传，单线程下载）//记录已上传和分片的部分，断开后只需要续传未完成的部分即可
- 文件预览（支持图片、文本、部分视频格式）
- 文件删除（支持回收站机制，非永久删除）
- 文件重命名（已实现）
- 文件移动（已实现）
- 文件夹创建、删除、重命名(已实现)

### 2. 文件管理与浏览

- 文件列表浏览（支持分页/刷新）
- 回收站（支持误删恢复与彻底删除）
- 文件搜索 (实现完成)
- 文件排序（暂未实现）
- 文件/文件夹批量操作（支持多选上传，部分批量操作）

### 3. 用户与权限

- 用户注册、登录、登出
- 用户个人空间配额管理（已实现）
- 多用户支持（每个用户独立空间，暂未实现团队/共享空间）
- 文件/文件夹分享（暂未实现外链分享）
- 权限控制（基础鉴权，暂未实现细粒度权限）

### 4. 版本与历史

- 操作日志（服务端日志，未对用户开放）
- 文件历史版本管理（暂未实现）

### 5. 安全与隐私

- 文件传输加密（依赖操作系统和局域网，未实现端到端加密）
- 用户密码加盐哈希存储
- Token 鉴权
- 防盗链、防刷下载（暂未实现）
- 文件访问审计（暂未实现）

### 6. 体验与扩展

- 在线预览（支持图片、文本、部分视频文件预览）
- 文件标签/备注（暂未实现）
- 离线下载/任务队列（暂未实现）
- 多终端支持（已实现 PC 端 Qt 客户端，Web/移动端暂未实现）
- API/SDK 支持（暂未开放）

### 7. 性能与高可用

- MinIO 分布式对象存储后端，支持高可用和扩容
- 支持大文件分片上传与合并
- 数据冗余与备份（依赖 MinIO 配置，项目本身未实现）
- 异地容灾（未实现）

### 8. 其他增值功能

- 文件外链统计（未实现）
- 文件分享二维码（未实现）
- 邮件/短信通知（未实现）
- 第三方云盘互通（未实现）

---

**说明：**
- 以上为当前 Nimbus 项目已实现与部分规划功能，实际功能以源码和客户端界面为准。
- 后续可根据需求逐步扩展更多高级功能。
