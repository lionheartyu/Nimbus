# 1.背景

* 我们致力于用C++实现一个高效的云存储系统，它的名字叫做Nimbus!
* 用 C++ 及上述技术开发云盘系统，能兼顾高性能、可扩展性、跨平台和专业 UI，适合对性能和稳定性要求高的场景。

# 2.架构流程图设计

* **底层网络，存储逻辑流程**

```bash
# Nimbus 云盘系统架构流程图（Nginx 版）

[客户端]
    |
    v
[Nginx API网关/负载均衡]
    |
    v
[muduo服务器集群]
    |
    +--(注册/登录)--> [Redis: 会话/缓存] <--> [MySQL: 用户表]
    |
    +--(文件操作, protobuf序列化/反序列化)-->
    |                |
    |        [统一存储接口层/微服务]
    |                |
    |      +---------+---------+
    |      |                   |
    v      v                   v
 [Ceph:文件内容]          [MySQL: 文件元数据表]
                                 ^
                                 |
                         [Redis: 热点元数据缓存]
                         
- Nginx 作为 API 网关和负载均衡，将请求分发到 muduo 服务器集群。
- 注册/登录请求优先查 Redis，再查 MySQL 用户表。
- 文件操作通过统一存储接口层，调用 Ceph存储文件内容，文件元数据存储在 MySQL，热点数据缓存到 Redis。
```

* **UI和底层逻辑的交互实现**

```bash
[Qt UI界面] <----> [你的C++业务逻辑/网络/存储代码]
```

# 3.源码项目目录

```bash
Nimbus/
├── CMakeLists.txt           # CMake 构建脚本
├── README.md
├── docs/                    # 项目文档、架构图等
├── proto/                   # protobuf 协议文件
│   └── file.proto
├── src/                     # 主要 C++ 源码
│   ├── main.cpp             # 程序入口
│   ├── server/              # muduo 服务器相关代码
│   │   ├── server.h
│   │   └── server.cpp
│   ├── storage/             # 统一存储接口层
│   │   ├── storage_interface.h
│   │   ├── ceph_client.cpp
│   │   └── fastdfs_client.cpp
│   ├── db/                  # 数据库/Redis 访问模块
│   │   ├── mysql_client.cpp
│   │   └── redis_client.cpp
│   ├── model/               # 数据模型（如用户、文件元数据）
│   │   ├── user.h
│   │   └── file_meta.h
│   └── utils/               # 工具类/通用代码
│       └── logger.h
├── ui/                      # Qt 客户端代码
│   ├── mainwindow.ui
│   ├── mainwindow.cpp
│   └── ...
├── scripts/                 # 部署、启动、测试脚本
│   ├── start_nginx.sh
│   ├── deploy_ceph.sh
│   └── ...
├── conf/                    # 配置文件（nginx.conf, ceph.conf, fastdfs.conf等）
│   ├── nginx.conf
│   ├── ceph.conf
│   └── fastdfs.conf
└── third_party/             # 第三方库（如 muduo、protobuf、FastDFS C client等）
```

- `proto/`：存放 protobuf 协议定义文件。
- `src/server/`：muduo 服务器主逻辑。
- `src/storage/`：统一存储接口层，封装 Ceph/FastDFS API。
- `src/db/`：数据库和 Redis 访问代码。
- `src/model/`：数据结构定义（如用户、文件元数据）。
- `ui/`：Qt 客户端界面及逻辑。
- `conf/`：各类配置文件。
- `scripts/`：部署和启动脚本。
- `third_party/`：第三方依赖源码或编译产物。
