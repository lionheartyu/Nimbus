* 用 C++ 及上述技术开发云盘系统，能兼顾高性能、可扩展性、跨平台和专业 UI，适合对性能和稳定性要求高的场景。

# 2. 架构流程图设计

## 2.1 当前 Nimbus 架构（实际部署版）

```bash
# Nimbus 云盘系统实际部署架构

[Qt 客户端/CLI]
    |
    v
[muduo 服务器 (Nimbus Server)]
    |
    +--(注册/登录/鉴权)--> [MySQL: 用户表 & 会话表]
    |
    +--(文件操作, protobuf序列化/反序列化)-->
    |                |
    |        [MinIO/S3 存储接口]
    |                |
    v                v
 [MinIO: 文件内容]   [MySQL: 文件元数据表]
```

- 客户端通过 protobuf 协议与 muduo 服务器通信。
- 用户注册、登录、鉴权等操作由 MySQL 管理。
- 文件上传、下载、删除等操作通过 MinIO（S3 协议）进行对象存储，文件元数据也存储在 MySQL。
- 支持高并发、断点续传、大文件分片上传等。

## 2.2 可扩展架构（支持 Nginx/Redis/Ceph）

> 未来可扩展为下图，支持 API 网关、缓存、分布式存储等：

```bash
[客户端]
    |
    v
[Nginx API网关/负载均衡]
    |
    v
[muduo服务器集群]
    |
    +--(注册/登录)--> [Redis: 会话/缓存] <--> [MySQL: 用户表]
    |
    +--(文件操作, protobuf序列化/反序列化)-->
    |                |
    |        [统一存储接口层/微服务]
    |                |
    |      +---------+---------+
    |      |                   |
    v      v                   v
 [Ceph/MinIO:文件内容]    [MySQL: 文件元数据表]
                                 ^
                                 |
                         [Redis: 热点元数据缓存]
```

- Nginx 作为 API 网关和负载均衡，将请求分发到 muduo 服务器集群。
- 注册/登录请求优先查 Redis，再查 MySQL 用户表。
- 文件操作通过统一存储接口层，调用 Ceph/MinIO 存储文件内容，文件元数据存储在 MySQL，热点数据缓存到 Redis。

# 3. 源码项目目录

```bash
Nimbus/
├── CMakeLists.txt           # CMake 构建脚本
├── README.md                # 项目说明与部署文档
├── docs/                    # 项目文档、架构图等
│   └── 架构设计.md
├── proto/                   # protobuf 协议文件
│   └── file.proto
├── src/                     # 主要 C++ 源码
│   ├── main.cpp             # 服务端程序入口
│   ├── server/              # muduo 服务器相关代码
│   │   ├── file_server.h
│   │   ├── file_server.cpp
│   │   ├── file_server_util.h
│   │   ├── file_server_util.cpp
│   │   ├── file_server_chunk.h
│   │   ├── file_server_chunk.cpp
│   │   ├── file_server_db.h
│   │   └── file_server_db.cpp
│   ├── storage/             # 存储接口层（MinIO/S3）
│   │   ├── minio_storage.h
│   │   └── minio_storage.cpp
│   ├── client/              # Qt 客户端代码
│   │   ├── file_client_windows.h
│   │   ├── file_client_windows.cpp
│   │   ├── login_dialog.h
│   │   ├── login_dialog.cpp
│   │   ├── register_dialog.h
│   │   ├── register_dialog.cpp
│   │   └── main.cpp
│   └── CMakeLists.txt       # 源码 CMake 构建脚本
├── ui/                      # Qt 客户端界面文件（如有）
├── scripts/                 # 部署、启动、测试脚本
│   ├── start_minio.sh
│   ├── init_mysql.sql
│   └── ...
├── conf/                    # 配置文件（如 minio.conf, mysql.conf 等）
└── third_party/             # 第三方库（如 muduo、protobuf、aws-sdk-cpp 等）
```

- `proto/`：存放 protobuf 协议定义文件。
- `src/server/`：muduo 服务器主逻辑。
- `src/storage/`：MinIO/S3 存储接口层。
- `src/client/`：Qt 客户端主逻辑。
- `conf/`：各类配置文件。
- `scripts/`：部署和启动脚本。
- `third_party/`：第三方依赖源码或编译产物。
