# Nimbus 云盘系统性能测试文档

## 1. 测试目的

评估 Nimbus 云盘系统在高并发、大文件传输等场景下的性能表现，验证系统的稳定性和可扩展性。

## 2. 测试环境

- 服务端操作系统：Linux (Ubuntu 20.04)
- 客户端操作系统：Windows 10 / Linux
- 主要依赖：MinIO、MySQL、Qt5、Protobuf、Muduo
- 测试工具：自定义 Python/C++ 压力测试脚本、ab、wrk、htop、iftop、iotop

## 3. 性能测试用例

| 用例编号 | 测试内容   | 操作步骤                                     | 预期结果                   |
| -------- | ---------- | -------------------------------------------- | -------------------------- |
| PT-01    | 并发上传   | 10/50/100 客户端同时上传 10MB 文件           | 服务端无崩溃，上传速率合理 |
| PT-02    | 并发下载   | 10/50/100 客户端同时下载同一大文件           | 下载速率合理，内容无损     |
| PT-03    | 大文件传输 | 上传/下载 1GB 文件                           | 传输成功，断点续传有效     |
| PT-04    | 空间压力   | 持续上传文件至空间接近满                     | 空间统计准确，系统无异常   |
| PT-05    | 资源占用   | 高并发上传/下载时监控 CPU/内存/网络/磁盘资源 | 资源占用在可控范围，无泄漏 |
| PT-06    | 响应时间   | 记录高并发下文件操作的平均响应时间           | 响应时间合理，无明显延迟   |
| PT-07    | 稳定性测试 | 长时间持续并发上传/下载                      | 系统稳定运行，无崩溃       |

## 4. 测试方法

- 使用自定义多线程脚本模拟多用户并发上传、下载文件。
- 利用 ab、wrk 等工具对 REST API（如有）进行压力测试。
- 通过 htop、iftop、iotop 等工具实时监控服务器 CPU、内存、网络、磁盘等资源占用。
- 记录每个操作的耗时、成功/失败次数、系统资源变化。
